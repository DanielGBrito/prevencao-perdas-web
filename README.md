# Dashboard - Prevenção de Perdas

Este projeto é uma aplicação web simples desenvolvida para apresentar os resultados de um modelo de Machine Learning aplicado à prevenção de perdas no varejo.

## 🧰 Tecnologias Utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Chart.js

## 📄 Funcionalidades
- Exibição de uma tabela com score de risco por loja.
- Gráfico de barras com tipos de perda (quebra/desvio).
- Layout responsivo para visualização em dispositivos móveis.

## 🔍 Como visualizar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no seu navegador.
